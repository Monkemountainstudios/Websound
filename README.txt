SILENT MACHINE GENERATOR — VERSION 2.0

Upload index.html, style.css and generator.js to the root of the Websound repository.
Keep the existing audio folders in place.

New in V2.0:
- Normal / Glacial performance modes
- Glacial Mode uses four randomly selected voice slots
- All six voice types remain available, including drums
- Duplicate voice types are allowed
- One slot evolves at a time
- Slower Glacial evolution intervals
- Ochre-yellow status LED
- Slowly breathing LED while Glacial Mode is active
- Proper stopping and disconnection of outgoing voices
- Playback-oriented AudioContext buffering

The embedded iframe will need to be approximately 235 px tall.
